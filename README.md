# UGM Timer

Fullscreen countdown timer for tablets, with optional presenter/admin
peer-to-peer pairing. Static site, no backend, no build step.

Hosted on GitHub Pages from `main` / root.

## Development

Just open `index.html` in a browser, or serve the folder with any static
file server (needed for service worker / PWA testing).

## Status

Work in progress — see `TASKS.md` for the implementation plan.
